# Clickable path

Folder names before the current folder in the location bar are clickable. Click a parent folder
to navigate there; the cursor selects the folder you came from. Hovering a parent name shows a
hand pointer and highlights the path prefix that will open.

Clicking the current folder name or the empty space after the path still opens Go To. Clickable
paths are on by default. Run **Toggle clickable path** in the command palette to turn the feature
off or on. The choice is saved in `%APPDATA%/fman/Local/Settings.json` under `clickable_path`.
